# Инструкция по тестированию Telegram-бота

Бот: **@botbot12234bot**

Ниже — пошаговый сценарий, как проверить, что бот делает всё, что должен. Каждый пункт — конкретное действие и то, что должно произойти в ответ.

---

## Перед началом

1. Убедитесь, что у вас есть доступ к Telegram-аккаунту, который назначен администратором бота, и к каналу, на который бот проверяет подписку.
2. Откройте бота: **@botbot12234bot**.
3. Если ранее уже переписывались с ботом — на всякий случай нажмите `/start` заново, чтобы начать сценарий с чистого листа.

---

## 1. Основной пользовательский сценарий

| Шаг | Действие | Что должно произойти |
|---|---|---|
| 1.1 | Отправить `/start` | Приходит приветствие с тремя кнопками: **Да**, **Розыгрыш**, **Написать специалисту** |
| 1.2 | Нажать **Да** | Приходит сообщение с просьбой подписаться на канал, кнопки **Перейти к каналу** и **Проверить подписку** |
| 1.3 | Нажать **Проверить подписку**, НЕ подписавшись | Всплывает предупреждение, что подписки ещё нет |
| 1.4 | Подписаться на канал, затем нажать **Проверить подписку** ещё раз | Приходит «Спасибо что подписался...», затем текст с кнопками **Получить инструкцию** и **Написать специалисту** |
| 1.5 | Нажать **Получить инструкцию** | Приходит инструкция, затем блок «Альфа Банк» (текст + картинка, если она загружена в админке), затем инструкция по отправке PDF |
| 1.6 | Отправить любой PDF-файл (не фото, именно документом) | Бот присылает: «Файл получен ✅ (заявка №N)», статус, и сумму («Страховка на сумму: ...») |
| 1.7 | Проверить чат администратора | В админский чат приходит уведомление: имя/ник пользователя (кликабельно), дата активации, теги (#Новичок #Профи), **та же сумма**, статус, номер заявки и имя файла, кнопка **Ответить** |
| 1.8 | Администратор нажимает **Ответить** и пишет текст | Пользователю приходит этот текст, администратору — «Вы ответили ✅» |

### Как проверить, что сумма считается правильно

Бот считает переплату так: открывает присланный PDF, ищет в тексте выписки строки со словом **«страх»** (по умолчанию — покрывает «страхование», «страховая защита» и т.п.) и складывает суммы по этим строкам.

**Чтобы проверить вручную:** откройте свою PDF-выписку, найдите глазами все строки со словом «страх», сложите указанные там суммы — результат должен совпасть с тем, что показал бот (сообщение пользователю и уведомление администратору всегда показывают одну и ту же сумму, они читаются из одной и той же заявки).

Если в файле НЕТ строк с этим словом или файл — отсканированная картинка без текста (не настоящий PDF-текст) — бот честно скажет «сумма не определена» и предложит написать специалисту. Это ожидаемое поведение, а не ошибка: автоматика — это подсказка, а не замена специалиста.

**Ключевое слово можно поменять** без участия программиста: `/admin` → **Настройки** → `setting_calculation_keyword`.

|---|---|---|
| 2.1 | На главном экране нажать **Розыгрыш** | Текст с описанием призов, кнопки **Подписаться на канал**, **Отправить пост**, **Назад** |
| 2.2 | Нажать **Отправить пост** | Инструкция по репосту, кнопки **Открыть пост** (если задана ссылка), **Участвовать**, **Назад** |
| 2.3 | Нажать **Участвовать** (без подписки) | Предупреждение, что нужно сначала подписаться |
| 2.4 | Подписаться, нажать **Участвовать** снова | «Вы успешно зарегистрированы в розыгрыше!» |
| 2.5 | Нажать **Участвовать** ещё раз | «Вы уже участвуете» — повторно засчитано не будет |

## 4. Админ-панель

Откройте `/admin` от лица администратора (Telegram ID указан в настройках бота).

| Раздел | Что проверить |
|---|---|
| **Пользователи** | Список пользователей, поиск по имени/username/ID, карточка пользователя (теги, файлы, заявки, история сообщений, история действий) |
| **Рассылки** | Добавить рассылку → текст → фото/без фото → предпросмотр → аудитория (все / активированные / по тегу / отправившие файл) → время (сейчас / через 2 часа / другое время) → подтверждение. После отправки — статистика (доставлено/ошибок) |
| **Розыгрыши** | Список, создание нового розыгрыша, включение/выключение |
| **Подписки** | Статистика подписавшихся, ссылка/название канала |
| **Уведомления** | Журнал уведомлений, ответ пользователю через кнопку «Ответить» |
| **Статистика** | Общие цифры: пользователи, подписки, файлы, заявки, рассылки |
| **Контент** | Редактирование всех текстов бота (приветствие, инструкции и т.п.) и картинки «Альфа Банк» |
| **Настройки** | Ссылка/название канала, ссылка на пост розыгрыша, ключевое слово для расчёта переплаты — всё меняется без участия программиста |

## 5. Известные ограничения (это не баги)

- **Расчёт суммы** — это эвристика по ключевому слову, а не бухгалтерская программа. Она отлично работает на реальных PDF-выписках с текстовым слоем (проверено на выписках Альфа-Банка и Т-Банка). Если банк оформляет выписку принципиально иначе (например, без слова «страх» в описании операции) — сумма не определится автоматически, и это по замыслу подхватывает специалист.
- **Формула переплаты** (сколько именно можно вернуть по закону) в это ТЗ не входила и не была передана — бот считает **сумму фактически списанных платежей по страхованию**, а не итоговую сумму к возврату по праву. Юридический расчёт — отдельная задача.
- Бот проверяет подписку по-настоящему через Telegram API — если после подписки кнопка «Проверить подписку» не сработала сразу, подождите несколько секунд (иногда Telegram отдаёт статус подписки с небольшой задержкой) и нажмите ещё раз.

## 6. Если что-то не работает

Проверьте по порядку:
1. Бот вообще отвечает на `/start`? Если нет — возможно, бот выключен/сервер недоступен.
2. Есть ли у бота права администратора в канале для проверки подписки? (Настройки канала → Администраторы → должен быть добавлен бот)
3. Актуальны ли ссылка на канал и ключевое слово в `/admin` → Настройки?

Если проблема не решается — опишите точный шаг, на котором что-то пошло не так, и приложите скриншот переписки с ботом.
